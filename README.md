### Хобби: делаю игры 🎮

По вечерам собираю браузерные мини-игры для **VK Mini Apps**, **Яндекс Игр**, **RuStore** и **Telegram**. Начиналось с одной игры «просто попробовать», а теперь их десятки: аркады, головоломки, раннеры, мерджи и даже пара 3D-игр. Кажется, хобби немного вышло из-под контроля.

Чему это меня научило:
- доводить до релиза, а не до «почти готово»;
- выжимать производительность из слабых телефонов;
- проходить модерацию четырёх разных платформ и не терять веру в людей.
